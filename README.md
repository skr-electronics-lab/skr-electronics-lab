## 🛠️ What I work on

- **IoT & Edge AI firmware** — ESP32/ESP32-S3: security cameras, AI voice assistants, MCP servers, aircraft radars
- **Android & Flutter apps** — published engineering tools on Google Play
- **Arduino libraries** — button handling, OLED keyboards, LED effects
- **Blogging & teaching** — full build tutorials + a 16-calculator engineering [Tools Hub](https://skrelectronicslab.com/engineering-tools-hub/)

## 🔥 Featured projects

| Project | What it does |
|---|---|
| 📡 [**FlyRadar32**](https://github.com/skr-electronics-lab/flyradar32) | Live ADS-B aircraft radar on ESP32 + ST7735 — multi-provider data, captive-portal Wi-Fi, web dashboard, 3 radar themes |
| 📱 [**Resistor Decoder**](https://play.google.com/store/apps/details?id=com.skrelectronicslab.resistor_decoder) | My Android app on Google Play — 8 professional electronics calculators with circuit diagrams, offline |
| 📷 [**MotionCam-S3**](https://skrelectronicslab.com/build-your-own-smart-security-camera-motioncam-s3-using-esp32s3-cam-module/) | Production ESP32-S3 security camera firmware — motion detection, Telegram alerts, PIN-secured dashboard |
| 🤖 [**ZhiNode MCP Server Pro**](https://skrelectronicslab.com/zhinode-mcp-server-pro/) | Turns an ESP32 into the physical body for Xiaozhi AI — sensors, relays & voice control via MCP |
| 🎨 [**PixGen32**](https://skrelectronicslab.com/pixgen32-esp32-s3-ai-image-generator/) | Voice-controlled AI image generator — talk to your ESP32-S3 and get generated art |
| 🖱️ [**ESP32-Air-Mouse-Pro**](https://github.com/skr-electronics-lab/ESP32-Air-Mouse-Pro) | Control your PC cursor in mid-air — ESP32 + MPU6050 |
| ⌨️ [**OLEDKeyboard**](https://github.com/skr-electronics-lab/OLEDKeyboard) | Non-blocking on-screen keyboard library for U8g2 OLED displays |
| 🔘 [**SKRButton**](https://github.com/skr-electronics-lab/SKRButton) | Advanced button library — long-press, double-tap, toggle, and more |
