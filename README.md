## 📡 IoT & Edge AI projects

| | Project | What it does |
|---|---|---|
| 📡 | [**FlyRadar32**](https://github.com/skr-electronics-lab/flyradar32) | Live ADS-B aircraft radar on ESP32 + TFT — multi-provider data, captive-portal Wi-Fi, web dashboard, 3 themes |
| 📷 | [**MotionCam-S3**](https://skrelectronicslab.com/build-your-own-smart-security-camera-motioncam-s3-using-esp32s3-cam-module/) | ESP32-S3 security camera firmware — motion detection, Telegram alerts, PIN-secured dashboard |
| 🤖 | [**ZhiNode MCP Server Pro**](https://skrelectronicslab.com/zhinode-mcp-server-pro/) | Gives Xiaozhi AI a physical body — ESP32 sensors, relays & voice control via MCP |
| 🎨 | [**PixGen32**](https://skrelectronicslab.com/pixgen32-esp32-s3-ai-image-generator/) | Voice-controlled AI image generator — talk to your ESP32-S3, get generated art |
| 🖱️ | [**ESP32-Air-Mouse-Pro**](https://github.com/skr-electronics-lab/ESP32-Air-Mouse-Pro) | Control your PC cursor in mid-air — ESP32 + MPU6050 |
| 📐 | [**MotionSync3D**](https://github.com/skr-electronics-lab/MotionSync3D-ESP32) | 3D motion-sync firmware for ESP32 with a browser-based installer |
